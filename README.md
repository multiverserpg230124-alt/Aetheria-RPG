# Aetheria-RPG

Repositorio de desarrollo y respaldo de la skin personalizada de Aetheria-RPG.

## Información

- Plataforma: ForoActivo
- Versión: phpBB3
- Estado: En desarrollo
- Repositorio utilizado como copia maestra de la skin.

---

## Estructura

### CSS

La carpeta `/css` contiene los estilos principales del foro.

Archivo principal:

`stylesheet.css`

Este archivo corresponde al CSS Stylesheet de ForoActivo.

---

### JavaScript

La carpeta `/javascript` contiene los módulos JavaScript utilizados en el foro.

Cada archivo corresponde a un código JavaScript configurado en:

Panel de administración → Módulos → HTML & JavaScript → Gestión de los códigos JavaScript.

---

### Templates

La carpeta `/templates` contiene los templates personalizados del foro.

Estos archivos corresponden a:

Panel de administración → Visualización → Templates → General.

---

## Flujo de trabajo

1. El código estable se mantiene respaldado en GitHub.
2. Las modificaciones se realizan sobre archivos del repositorio.
3. Los cambios se prueban en ForoActivo.
4. Si funcionan correctamente, se conservan como versión estable.
5. GitHub permite recuperar versiones anteriores si ocurre algún problema.
